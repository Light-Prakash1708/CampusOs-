# Pilot records

These are the working records of the first pilot. They hold **real entries only**: no invented interviews, quotes or numbers. An empty table means nothing has happened yet.

| File | What goes in it |
|---|---|
| [ISSUE_LOG.md](ISSUE_LOG.md) | Every problem found in production or reported by the college, classified A–F |
| [FEEDBACK_LOG.md](FEEDBACK_LOG.md) | Structured feedback from principals, the IQAC, faculty and students |
| [FEATURE_REQUESTS.md](FEATURE_REQUESTS.md) | Requests and the gate each must pass before anything is built |
| [METRICS.md](METRICS.md) | The weekly pilot numbers, preserved week by week |
| [csv-templates/](csv-templates/) | Header-only import templates for the college |
